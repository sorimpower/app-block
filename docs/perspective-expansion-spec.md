# 유튜브 분석 기능 명세

## 목적

YouTube 시청 기록을 단순 보관하지 않고 사용자가 접한 주제·주장·관점을 구조화한다. 사용자의 성향이나 편향을 점수화하지 않으며, 콘텐츠 노출 범위와 아직 탐색하지 않은 질문만 보여준다.

## 사용자 흐름

1. 알림 접근 권한으로 활성 YouTube MediaSession을 직접 구독한다.
2. MediaSession 변화 콜백과 30초 주기 확인으로 제목·채널·재생 길이·현재 위치·가능한 경우 videoId를 자동 기록한다.
3. 2분 이상이면서 전체 길이의 50% 이상 본 새 영상만 GPT-5.6 Luna에 제목·채널을 보내 저비용 주제 분류를 수행한다.
4. 승인한 기존 주제와 일치하면 자동 연결하고, 새로운 주제는 로컬 알림과 주제 관리 화면에서 등록 여부를 확인한다.
5. 사용자가 `다른 관점 보기 · Terra`를 누르면 YouTube Data API의 제목·채널·설명·태그·챕터·공개 메타데이터와 확보 가능한 공개 자막을 GPT-5.6 Terra medium에 전달한다.
6. 사용자가 `영상 정밀 분석 · Gemini 3.5 Flash`를 누를 때만 Gemini에 실제 공개 YouTube 영상 URL을 전달하여 화면·음성 맥락까지 분석한다. Gemini 실패 시 GPT 폴백은 하지 않는다.
7. 분석에서 최대 네 개의 서로 다른 사고축을 만들고 결과를 캐시한다.
8. 관점별 검색어를 YouTube Data API로 조회해 실제 추천 영상 최대 2개를 카드로 보여준다. 링크를 여는 것만으로는 탐색 완료로 보지 않으며, 추천 영상을 MediaSession에서 2분 이상 시청했을 때만 생각 흐름에 반영한다.

## 화면

### 홈

- 기능 소개용 히어로 카드를 사용하지 않고 실제 사용자 데이터를 첫 화면부터 노출
- 최근 내 관심: 현재(7일), 1개월, 3개월, 1년의 의미 있는 시청 주제 비율
- 최근 사고 확장: 실제 선택한 관점 경로와 마지막 확장 시점
- 내가 안 본 세상: 최근 영상에서 생성됐지만 아직 선택하지 않은 관점 최대 3개
- 생각이 넓어진 순간: 이동 전후 관점을 사용한 사용자 중심 문장과 발생일
- 최근 시청 요약: 자주 본 주제와 아직 보지 않은 관점을 그래프로 비교

### 사고 지도

- 주제별 지도
- 실제 시청 영상 썸네일과 시작 영상 표시
- 2분 이상 본 영상과 실제 탐색한 관점은 초록색, 아직 보지 않은 관점은 회색으로 표시
- 완료 경로는 초록색, 추천 경로는 회색으로 구분
- 완료 노드에는 실제 시청·탐색 순서를 숫자로 표시
- 지도 노드와 하단 관점 목록을 누르면 원본 영상·추천 영상·전체 시청 순서를 확인

### 탐색

- MediaSession 권한은 설정 완료 시 한 줄 상태로 축소
- 가장 최근 자동 감지 영상을 첫 콘텐츠로 노출
- 최근 영상의 요청형 심층 분석과 다른 관점 최대 4개를 우선 표시
- 이전 영상의 미탐색 관점과 실제 추천 YouTube 영상 연결

### 리포트

- 이번 주 시청 요약
- 이번 주 관심 주제 비율을 단일 색상의 막대그래프로 시각화
- `원래 본 영상 → 선택한 관점 → 2분 이상 본 추천 영상`을 썸네일 경로로 표시
- 점수·성향 판정 없이 노출 콘텐츠만 서술

### 기록

- 최근 자동 감지 영상 목록
- 영상별 분석 여부와 재분석 진입
- 상단 `주제 관리`를 통해 설정 성격의 관리 화면으로 이동

### 주제 관리

- 상단 메인 탭에서는 제외하고 기록 화면의 관리 진입점으로 제공
- Gemini가 제안한 새 주제의 등록/건너뛰기
- 사용자가 등록한 주제의 이름·설명 수정 및 주제별 수집 ON/OFF
- OFF 시 신규 분류·분석·추천에서 제외
- 기존 기록은 보존

## 데이터 및 캐시

전용 Room DB `perspective.db`를 사용한다.

- `perspective_topics`
- `topic_suggestions`
- `watched_videos`
- `video_topics`
- `video_analyses`
- `perspectives`
- `thought_nodes`
- `thought_edges`
- `expansion_moments`
- `weekly_perspective_reports`

심층 분석 캐시 키는 영상 ID, 공개 메타데이터·자막 해시, 분석 모드, 프롬프트 버전으로 구성한다. 동일 영상·동일 공개정보·동일 또는 상위 분석 모드는 다시 AI 분석하지 않는다.

## 자동 감지 범위와 한계

Android NotificationListener와 MediaSession에서 다음을 가능한 범위로 읽는다.

- 영상 제목
- 채널/작성자
- 재생 길이
- 현재 재생 위치
- Media ID

YouTube 앱이 실제 `videoId`를 MediaSession에 제공하지 않는 기기·버전이 있다. 이 경우 제목·채널의 높은 유사도 검색으로만 공개 영상을 연결하며, 일치 여부가 불확실하면 분석을 중단한다. 자막은 공개적으로 제공되고 서버에서 확보 가능한 경우에만 입력으로 사용한다. 앱은 접근성 UI를 조작하거나 사용자의 YouTube 계정 시청 기록을 우회 수집하지 않는다.

## 비용 방어

- MediaSession 자동 감지와 30초 위치 갱신은 AI를 호출하지 않는다.
- 의미 있게 본 새 영상 하나당 주제 분류를 최대 한 번만 호출한다.
- 주제 분류 입력은 제목·채널·승인 주제명뿐이며 출력은 최대 128토큰 JSON으로 제한한다.
- 기존 승인 주제와 일치한 영상은 새 주제 알림을 만들지 않는다.
- 기본 심층 분석은 사용자가 버튼을 누른 영상만 Terra medium으로 실행하며, Gemini 실제 영상 분석은 별도 정밀 버튼에서만 실행한다.
- 관점별 실제 영상 추천은 분석 직후 최대 4개 검색어를 조회하며, 결과를 로컬 DB에 캐시한다.
- 영상 분석 결과 하나를 지도·뇌 지도·안 본 세상·확장 순간·리포트에 재사용한다.
- 주간 리포트의 빈도 집계는 로컬에서 수행한다.

## 현재 MVP와 다음 단계

현재 추천은 검증된 YouTube 검색어를 연다. YouTube Data API 키가 준비되면 후보 5~10개 검색, 메타데이터 필터, 상위 후보 영상 검증, 최종 추천 카드까지 확장할 수 있다.
