# AI 알림 기능 명세

## 목적

사용자가 허용한 휴대폰 데이터를 통합 분석해 기한·예약·쿠폰·금융·해야 할 일을 찾아 챙김 카드와 알림으로 제공한다.

## 분석 데이터

사용자가 각각 켜고 범위 또는 대상 앱·폴더를 선택한다.

- 문자
- 앱 알림
- 사진·이미지: 선택한 갤러리 폴더, 촬영일·위치 메타데이터
- 파일·문서: 선택 폴더 또는 Downloads
- 통화 녹음: 선택 폴더의 오디오 파일
- 앱 사용 기록: 선택 앱의 사용 패턴
- 캘린더
- 연락처: 문자·통화 발신자 이름 연결용
- 통화 기록

원본 데이터는 기기에 남기고, 분석 후보와 처리 상태만 로컬 DB에 저장한다.

## 수집·분석 흐름

1. 소스별 새 데이터만 수집한다.
2. 로컬 전처리로 OTP·명백한 광고 등 불필요한 문자를 줄인다.
3. 활성 소스의 후보를 통합 배치로 OpenAI에 전달한다.
4. AI가 해야 할 일, 기한, 예약, 쿠폰, 금융, 배송, 갱신, 안내 항목으로 구조화한다.
5. 유사 결과를 병합해 중복 카드를 줄이고 Room DB에 저장한다.

캘린더는 반복 일정의 실제 발생일을 읽는다. 현재부터 2주 안의 일정만 AI 후보로 전달하며, 2주 내 예약·약속·개인 일정은 반드시 챙김 후보로 추출하도록 지시한다.

## 노출 및 알림 정책

- 앱 내 `챙길 항목`: 기한이 있는 항목은 오늘부터 14일 이내에 표시한다. 쿠폰·교환권도 같은 14일 기준이다.
- 기한 없는 항목: AI 중요도가 높은 새 항목만 최대 14일간 표시한다.
- 정렬: 오늘 → 1~2일 내 → 중요 → 날짜순
- 오전 8시 자동 확인: 오늘 또는 내일 항목만 요약 푸시로 보낸다. 오후 7시 자동 확인은 예약하지 않는다.
- 개별 일정 시각 알림: 해당 항목의 dueAt 30분 전에 별도 알림을 예약한다. 이미 30분 이내인 일정은 가능한 즉시 한 번 알린다.
- 완료/넘기기: 카드와 해당 개별 알림에서 제외한다.

상단 정보 버튼에서는 `매일 오전 8시 새로운 일정 확인`을 안내한다.

## 화면

- `챙길 항목`: 우선순위 카드, 완료/넘기기 처리
- `분석 데이터`: 소스별 활성화, 권한 상태, 범위, 폴더·앱 선택, 최근 실행 정보

## 저장 및 권한

`phone_insights.db`에 소스 설정, 수집 처리 이력, AI 후보, 분석 결과, 실행·비용 이력을 저장한다. 각 데이터 소스는 Android 런타임 권한 또는 특별 접근 권한이 필요하다.
