# 경매 AI 권리분석 설정

## 현재 구현된 기반

- Firebase Functions를 거치는 OpenAI 구조화 JSON 응답 계약
- 법원 사건상세·현황조사서·감정평가 요약·매각물건명세서 메타데이터 자동 수집
- 사건 카드의 `AI 권리분석` 버튼에서 수집과 분석을 한 번에 실행
- 최신 등기사항전부증명서가 없으면 `PRELIMINARY`로 강제하고 확정 추천으로 표현하지 않음
- 예산·선호 구·최소 할인율·허용 위험도·점유 허용 여부·추가 요청을 DataStore에 저장
- WorkManager가 설정한 오전 시각에 새로 추가된 미분석 사건만 최대 5건 자동 분석하고 적합도순 최대 3건을 로컬 알림으로 표시
- 등기가 없더라도 사건상세·매각물건명세서·현황조사서가 모두 공개되고 위험도·적합도 조건을 통과한 결과는 `AI 예비 추천`으로 알림
- 사건별 분석 결과를 Room `auction_ai_analyses`에 캐시

## OpenAI 연결에 필요한 작업

1. Firebase Console에서 프로젝트를 만든다.
2. Android 앱 패키지 `com.sorimpower.app`을 등록한다.
3. Firebase Functions Secret Manager에 `OPENAI_API_KEY`를 등록한다.
4. 내려받은 `google-services.json`을 `app/google-services.json`에 둔다.
5. Google services Gradle 플러그인은 프로젝트와 앱 모듈에 적용되어 있다.
6. 디버그 빌드는 App Check debug provider, release 빌드는 Play Integrity provider를 사용한다.
7. 디버그 APK 최초 실행 시 Logcat에 출력되는 App Check debug token을 Firebase Console의 App Check 디버그 토큰에 등록한다.

`google-services.json`에는 프로젝트 식별 정보가 들어가지만 저장소에는 커밋하지 않는다. 현재 Gradle 플러그인, Firebase 초기화와 App Check 연결까지 완료되어 있다.

## 분석 단계

1. 법원 사건 상세 API에서 사건·물건 상세와 물건비고를 수집한다.
2. 문서 공개 기간이면 현황조사서, 감정평가 요약, 매각물건명세서 문서 메타데이터를 추가 수집한다.
3. ChatGPT가 구조화된 위험 항목과 추가 확인 사항을 생성한다.
4. 앱이 문서 충족 여부, 점수 범위, 상태를 다시 검증한다.
5. 등기 미포함 분석은 예비 분석으로만 표시한다.
6. 매일 아침 법원 목록을 새로고침하고, 오늘 새로 발견됐으며 AI 분석 이력이 없는 사건만 사용자 가격·지역 조건으로 최대 5건 선별한다.
7. 사건상세·매각물건명세서·현황조사서가 모두 있고 사용자 위험도·적합도 조건을 만족한 사건만 예비 추천 알림 후보로 만든다.
8. 적합도순 최대 3건을 하나의 알림으로 표시하고, 결과는 사건 카드에서도 다시 확인할 수 있다.

법원 사이트가 제공하는 감정평가·매각물건명세서 API에는 PDF 원문 대신 요약 또는 문서 메타데이터만 포함되는 경우가 있다. 프롬프트에는 이 차이를 명시하며, AI가 원문에 있을 법한 내용을 추측하지 못하도록 제한한다.

## 자동 추천 동작

- 경매 화면의 `AI 맞춤 경매 추천` 설정에서 기능과 조건을 저장한다.
- Android 13 이상에서는 알림 권한을 허용해야 결과 알림이 표시된다.
- 작업은 네트워크가 연결됐을 때 수행되며 Android 절전 정책에 따라 설정 시각보다 늦게 실행될 수 있다.
- 서버 푸시가 아니라 기기 내 WorkManager와 로컬 알림을 사용하므로 FCM 토큰이나 별도 서버는 필요하지 않다.
- 앱을 강제 중지하면 Android가 백그라운드 작업을 중단할 수 있으며, 앱을 다시 실행하면 저장된 예약을 복원한다.

## 다음 단계

- 사용자가 발급받은 최신 등기사항전부증명서 PDF를 사건에 연결하는 입력 경로
- 알림을 눌렀을 때 추천 사건만 모아 보여주는 전용 목록

## 주의

AI 결과는 입찰 결론이 아니라 문서 검토 보조 자료다. 법원 사이트도 입찰 전에 법원 비치 문서와 등기사항전부증명서를 다시 확인하도록 안내하므로, 앱에서도 근거 문서와 미확인 항목을 항상 함께 표시해야 한다.
