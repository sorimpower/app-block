# 부동산 경매 기능 명세

## 목적

서울 아파트 경매 사건을 앱에서 조회하고, 관심 사건·종료 결과·AI 권리 분석·추천을 관리한다.

## 사건 수집

- 법원 경매 API를 앱에서 직접 호출한다. GAS 중계는 사용하지 않는다.
- 수집 목록은 로컬 캐시를 사용해 탭 이동·정렬·검색 때 불필요한 호출을 줄인다.
- 새로고침 시에는 API를 다시 호출한다.
- 수집 조건은 화면 상단 정보 버튼에서 확인할 수 있다.

## 목록과 조작

상단 탭은 `진행`, `AI`, `관심`, `종료`다.

- 아파트명 검색, 정렬, 정렬 설정의 지속 저장
- 사건번호를 눌러 타경 뒤 사건번호만 복사
- 아파트명을 눌러 법원 경매 조회 페이지로 이동
- 지도는 지번뿐 아니라 아파트명 기준으로 네이버 지도 검색을 시도
- 관심 등록/해제
- 사건별 삭제 및 삭제 시 관심 목록에서도 함께 제거
- 매각기일·시각과 사건 정보를 기기 캘린더에 추가
- 새로 추가된 사건에 `NEW` 표시

## 종료 사건

진행 목록에서 사라진 사건은 로컬 종료 기록으로 이동한다. 종료 사건 API/공고 API로 낙찰·취하 등 최종 결과와 낙찰가를 확인해 표시한다. 각 기록은 개별 삭제할 수 있다.

## AI 분석과 추천

- 사건별 AI 권리 분석과 재분석
- 분석 모델 선택: Luna 또는 Terra
- 권리 위험, 핵심 요약, 확인할 사항을 사람이 읽기 쉬운 형태로 표시
- 매일 아침 추천 작업은 새로 추가된 사건만 대상으로 Luna 분석을 수행
- 추천 조건은 감정가 15억 이상, 점수·사용자 조건 등을 반영한다. 세대수는 현재 API 데이터의 정확한 제공 여부에 따라 추천 필수 조건으로 사용하지 않는다.
- 추천 결과가 있으면 푸시 알림과 앱 내 AI 탭에서 확인한다.

## 저장 및 백그라운드

`auction.db`에 사건, 관심, 종료 결과, AI 분석 기록을 저장한다. 추천 작업은 WorkManager로 실행된다.
