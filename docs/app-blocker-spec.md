# 앱 차단 기능 명세

## 목적

정해진 시간, 요일, 앱별 규칙에 따라 선택한 앱의 사용을 제한한다.

## 주요 기능

- 전체 차단 활성화/비활성화
- 요일·시작 시각·종료 시각 기반 차단 일정
- 매주·격주·매월 반복
- 앱별 차단 규칙과 예외 관리
- 차단 중인 앱 실행 시 전용 차단 안내 화면 표시
- 오늘의 차단 횟수와 상태 표시
- 민감한 설정 변경 시 비밀번호 보호

## 구현 방식

`AppBlockAccessibilityService`가 활성 앱 전환을 감지하고 현재 규칙과 비교한다. 차단 대상이면 `BlockedActivity`를 열어 원래 앱 사용을 막는다. 차단 판단과 일정 계산은 로컬에서 수행한다.

## 권한 및 주의사항

Android 접근성 권한이 필요하다. 제조사 절전 정책 또는 접근성 서비스 해제 상태에서는 차단이 동작하지 않을 수 있다.
