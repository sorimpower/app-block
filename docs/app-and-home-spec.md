# 앱 공통 및 홈 명세

## 화면 구성

하단 탭은 `홈`, `챙김`, `차단`, `기록`, `경매`, `더보기`로 구성한다. 앱을 열었을 때의 시작 화면은 설정에서 선택할 수 있다.

상단 헤더는 현재 기능 이름을 표시한다. 경매에는 수집 조건 정보 버튼이, AI 챙김에는 자동 확인 시간 안내 버튼이 있다.

## 홈

홈은 각 기능으로 이동하는 카드형 진입점이다.

- 앱 차단
- 건강 기록
- 부동산 경매
- AI 챙김

## 더보기 및 설정

더보기에는 설정과 앱 정보 카드가 있다. 앱 정보에는 현재 버전과 `집중을 위한 개인용 시스템` 소개를 표시한다.

설정에서는 다음을 관리한다.

- 시작 화면
- 앱 차단 접근성 권한
- 앱 잠금 비밀번호 설정·변경·제거

## 로컬 저장

공통 설정과 차단 설정은 앱 내부 저장소에 보관한다. 기능별 상세 데이터는 각 기능의 Room DB를 사용한다.
